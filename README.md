# MyRecipeApp

Recipe App is a modern Android application designed to help users browse and manage recipes with ease. It offers a structured and user-friendly interface for viewing ingredients, step-by-step instructions, and organizing meal ideas. it is build with MVVM design pattern by using both compose and xml layouts.


After setting up the environment clone this project to your desired location.

```bash
git clone git@github.com:253nomi/my_recipe_app_android.git
```
